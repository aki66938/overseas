# 客户端分发说明

## Windows 0.1.11

**分发给员工：一个 MSI 即可，不需要附带配置文件、DLL、证书文件或 SSH 脚本。**

前提：Windows x64、安装时具有管理员授权、位于公司内网，并已信任本包的签名证书。系统安全策略仍可能限制安装；不能通过忽略校验解决。

安装包内含 GUI、后台服务、Flutter 运行时、sing-box、Wintun、签名配置与校验清单、线路所需的指定 CA。安装器自动安装后台服务并校验/导入指定线路 CA。服务启动不代表自动连接。

员工操作：双击 MSI → 确认管理员授权 → 从开始菜单打开 RegenBio Overseas Access → 点击「开启海外访问」。日常操作不需要用户自行修改 DNS、导入线路证书、安装开发工具或部署 OpenSSH。

### 当前测试签名的限制

0.1.11 仍为 PoC 签名。未预置信任的新设备可能被包签名校验拒绝。MSI 包含证书文件，不等于操作系统已经信任该包；安装前信任校验不能由尚未通过校验的安装包自行绕过。

受管设备建议由 IT 使用域策略或 Endpoint Central 预置信任，再分发 MSI。员工只接触 MSI；信任配置属于 IT 部署前置条件。此说明没有执行全域证书下发。

签名身份有效期至 2026-09-30；该包已有可信 RFC3161 时间戳，但不能将此等同于永久可安装、永不需要维护。正式长期分发需要确定持续管理的签名身份，并验证新设备的完整信任链。

目前已验证测试机升级、签名/负载和服务；仍需一台未做过手工环境修复的新 Windows 设备执行首次安装验收。代理 CA 与浏览器独立证书策略的兼容性也需在目标浏览器实测。

| 平台 | 员工/IT 获得 | 使用方式 |
|---|---|---|
| macOS Apple Silicon | 一个签名并公证的 PKG | 安装后打开 GUI；首次可能需要系统扩展/VPN 授权，或由管理策略预批准 |

三端配置与指定证书均以包内预置为目标，不要求员工手动拼接文件。Linux 的系统依赖由包管理器处理；完全离线安装需要另行核对依赖，不能承诺只复制任意单包即可覆盖所有精简系统。

macOS 复用已确认紧凑 B 风格，Linux 仅 CLI。无企业账号登录、设备注册、自更新入口；仅用于公司内网。macOS 原生构建、系统扩展签名和公证需要真实 Mac、Xcode 与对应 Developer ID 资格，当前尚未核验。
