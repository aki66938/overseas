# Windows 轻量控制台改版

## 已确认方向

用户已确认浅灰绿背景、白色圆角卡片的轻量控制台方案。此次交付以 Windows 测试机 172.20.20.200 为准，部署后由用户评价实际视觉效果。

## 主页面

- 保持现有 460×540 逻辑窗口尺寸，与详情页一致。
- 使用统一间距、克制的阴影、深绿色主色，减少无意义的大块留白。
- 中央连接圆环、连接状态、连接时长与主操作形成明确层级；底部提供线路详情入口。
- 已连接时不根据站点探测质量显示黄色感叹号，不显示“部分目标响应较慢”“部分目标暂不可达”及同义提示。
- 真实的服务不可用、连接失败、恢复失败仍按实际状态展示；不将错误伪装成成功。
- 正在连接、断开及读取状态时保留忙碌反馈与重复操作保护。

## 详情页面

- 与主页同尺寸；紧凑的八行列表，站点左对齐、延迟右对齐，状态文字配小色点。
- 目标依次为 Google、Pinterest、Gemini、ChatGPT、Claude、TikTok、亚马逊、Facebook。
- 保留更新时间、历史结果标记、立即测速及真实不可达状态，不依赖颜色单独传达状态。
- 默认字号下八站点及底部操作完整可见；系统放大文字时允许滚动，不截断操作。
- 测量含义仍为 HTTPS 首响应延迟，不声称带宽、账号登录或 AI 功能可用。

## 探测与模块边界

- Flutter 主题与页面负责视觉呈现；状态模型负责目标映射和数据解析；Go lineprobe 负责目标定义与实际探测。
- 八目标清单在服务端、客户端校验及测试中保持一致，沿用已有调度与预算控制。
- Gemini 先采集实际错误类型，并比较当前根路径与浏览器使用的 /app、请求方法及响应头情况，再选择有证据支持的最小修复。
- 不预先认定 Gemini 根因；不跳过 TLS 验证、不伪造延迟、不把所有错误视为正常。

## 保持不变

连接与恢复流程、路由、防火墙和证书信任策略不因视觉改版调整。保留最小化、关闭及现有托盘行为，不增加最大化、登录、注册或检查更新功能。诊断日志默认关闭。此次不扩展 Mac/Linux 实现，不修改未完成的 Linux 草稿。

## 验收与部署

1. 为主页质量提示移除、八目标解析展示及探测修复添加回归测试。
2. Flutter 分析、组件测试和视觉基线覆盖主页、详情、忙碌、错误、历史结果及文字放大；检查两页尺寸一致与无溢出。
3. Go 探测及相关契约测试通过，Gemini 修复保留真实错误边界。
4. 提交本次代码，使用干净构建源生成新版本签名 MSI，校验签名及包内清单。
5. 在指定 Windows 测试机升级，核实安装版本、服务、已安装文件及 API；升级可能短暂断开海外访问。
6. 记录实际验证结果与未验证项，交由用户查看 GUI；保留既有回滚备份，不自动推送或合并主分支。
