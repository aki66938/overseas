# macOS 独立 TUN 联网 PoC

## 已确认目标

在 RB-LT-N40MJH（Apple Silicon）交付可以真实连接、访问海外站点、断开和重连的 GUI PoC。沿用紧凑 B 界面、八站点延迟列表，不新增登录或设备注册。Windows 不改动，Linux 暂缓。

本设计替代旧跨平台计划中本轮 macOS 必须采用 Packet Tunnel System Extension 的前提。当前 Xcode 27 RC、Flutter 3.47.2 构建已通过，但非 Windows 分支仍使用 UnavailableAccessClient，现有预览包不能联网。

## 路线选择

采用普通 Flutter GUI + root LaunchDaemon + 独立 sing-box TUN。系统扩展路线需要另行处理 entitlement 与分发条件，本轮不采用；纯 HTTP 系统代理不能充分验证原 TUN 方案，也不作为完成替代。

不要求 Developer ID、不关闭 SIP、不关闭 Gatekeeper，不移除 MDM。安装后台组件需管理员授权，正常连接和断开不要求反复输入密码。PoC 本地签名不等于已公证或正式企业分发资格。

## 组件和边界

1. 复用已有配置渲染、状态协议、站点探测模型；为 darwin 增加明确的平台适配，不直接套用 Windows DNS、路由和进程实现。
2. 后台服务负责 sing-box 生命周期、配置检查、网络快照及恢复。程序、节点配置和 launchd plist 为 root 所有且普通用户不可写；验证锁定核心的校验值，拒绝用户指定可执行文件或任意 shell 命令。
3. 本地 Unix socket 仅允许 root 与安装时确定的设备使用者访问；服务验证客户端身份。固定 API 为连接、断开、状态、探测，沿用版本和请求关联检查。GUI 以普通用户运行。
4. GUI 的 Mac 分支接入实际服务；成功启动进程不直接等于连接成功。必须验证 TUN 就绪和必要路由，站点结果独立显示在详情中，不在主页面增加“部分站点响应慢”文案。

## 网络与恢复

- 使用已验证的内网节点；先核对节点可达、DNS、现有代理、VPN 和默认路由，不根据旧记录盲改。
- 首次接管前持久化此次会话拥有的网络变更及原始设置；保存失败则不接管网络。
- 仅修改明确归属本应用的配置。不清空全局路由、防火墙或其他 VPN，不终止其他网络程序。
- 连接失败、主动断开、核心退出、服务重启均执行幂等清理。启动时先审计残留，再允许新连接；恢复失败明确报告，不假称已恢复。
- 测试前设置独立于 SSH 会话的限时恢复措施，保护内网管理路径。若无法保证可回退，先停止实机网络变更。
- 睡眠/网络切换后重新验证状态和接口；失效连接不得继续显示已连接。自动重连必须有界退避，避免反复接管网络。

## 证书和日志

上游链路若仍使用 Telecom GoMITM CA，先实测证书链，仅信任已核对指纹的指定 CA。流量 CA 与应用 PoC 签名证书不是同一回事；不跳过 TLS 校验。安装说明须明确这一信任变更，卸载不删除原本已存在的信任。

诊断日志默认关闭，开发验证时限时启用且脱敏。不记录密码、令牌或完整浏览器内容。截图测试现有差异保留为待验收项，不用更新基准掩盖失败。

## 交付与验收

交付单个 PoC 安装包，内含 GUI、后台服务、锁定的核心和必要配置；安装、卸载及恢复步骤随包提供。保留当前界面预览包，不将其覆盖为冒充功能已完成的产物。

以下证据齐备后才标记联网 PoC 通过：

- 配置、权限拒绝、并发请求、异常退出及恢复逻辑测试通过；Windows 相关回归测试不退化。
- Mac Release 构建与本地签名验证通过，实际 GUI 能连接后台。
- Google、YouTube、Pinterest、Gemini、ChatGPT、Claude、TikTok、Amazon、Facebook 按网络可达性与 HTTP 业务限制分开记录；延迟列表仍为已确认八站点，YouTube 额外用于浏览器测试。
- 实际浏览器访问、连续连接至少 60 分钟、主动断开恢复、重连、核心异常退出恢复均有证据。
- 睡眠唤醒由用户协助触发，记录结果；不能实测时明确保留未验收状态。
- 未通过的项目、现有限制和回滚方式明确列入交付说明。

Windows 连续连接 68 分钟说明既有 Windows 链路可持续工作，但不替代 macOS 平台验收。
